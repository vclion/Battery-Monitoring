# 0.2 本地验证记录

日期：2026-11-17。Windows 11 x64，源码存放在 WSL 共享目录，使用 Windows 侧 .NET Framework 编译。

## 自动检查

`scripts/build.ps1 -Test`：87 项检查通过。覆盖原迈从协议、错误帧、0% 与未知、手动快照、全黑图标及多尺寸 ICO、UTF-8 进程通信与超时，以及：

- Windows 系统报告的缓存标记；断开状态屏蔽缓存；无效类型、越界值与空值。
- BLE 单字节电量、0% / 100%、畸形长度、短与长 UUID、原生结构大小及字段偏移。
- 带中文、分隔符和换行的设备描述传输、设备身份校验及重复发现去重。
- 自动左右选择、明确选择后设备缺失不替换、单设备不重复占两侧。
- 本地选择配置读写、损坏配置回退、只存地址哈希而不存路径。
- 来源发现失败不丢失其他来源；单台模拟设备挂起并超时后，保留此前结果且继续查询后续设备。

测试使用合成设备与合成帧，不能视作新增品牌真机验收。测试产物在 `tests/artifacts/`，不进入源码包。

## 托盘交互

`tests/integration/ui-smoke.ps1`：真实 WinForms 消息循环检查通过，设备数据由合成工作进程提供。
检查了菜单结构、启动不查询、手动查询期间按钮禁用、实际选择菜单更新左右显示并保存、31 秒没有自动查询、再次查询取得新快照、退出移除图标。
使用项目内测试配置，没有更改当前用户的设备选择、开机启动或安装副本。

## 硬件范围

新版本 `--list` 已重新调用真实设备：V9 PRO 耳机返回 90%，L7 PRO 鼠标当前返回“休眠或未响应”，正确显示未知，未沿用旧百分比。
稍后再次查询时，V9 PRO 也出现过“电量读取超时”，对应结果正确变为未知；没有据此认定设备已断开，也没有声称完成持续在线或断开恢复验收。
发现 Windows Shell 设备目录只能通过带 `shell:::` 前缀的路径访问后已修正；本机该目录可枚举 13 个设备项目，但没有提供有效系统电量的外设。
本机当前仅枚举到蓝牙适配器，没有配对的 BLE 外设，因此没有新增品牌、BLE 真机读数或 Windows 外设电量缓存验收。
迈从早期真实电量与限制见 [0.1 历史记录](VALIDATION-LEGACY.md)。
