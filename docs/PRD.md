# Battery Monitor 0.2 需求边界

更新：2026-11-17。

## 目标

Windows 托盘显示两台可选设备的电量；保留全黑双半圆图标和仅手动查询，支持跨品牌的系统电量与标准 BLE 读取。设备兼容状态以 [COMPATIBILITY.md](COMPATIBILITY.md) 为准。

## 交互

1. 启动不查询；左键点击或右键“查询电量”发现设备并生成一次快照。
2. 一个全黑圆形轮廓分为左右两半，液面高度表示百分比，边框内和两半之间留白，无彩色或主题反色。
3. “设备电量”列出发现结果、来源、状态；菜单选择左右设备并保存在当前用户目录，明确选择的设备消失后不替换成其他设备。
4. 悬停显示名称、读数与查询时间；系统报告使用明确标记，设备更新时间可能未知。
5. 未查询、断开、睡眠、未知和失败显示黑色短横线；失败不沿用旧成功值。
6. 查询期间禁用查询按钮；单设备限时读取，托盘可退出。
7. 可选的当前用户开机启动；重复启动保持单实例，退出清理图标和查询进程。

## 读取与发布

- 原有迈从 L7 PRO、V9 PRO 的精确 HID 适配继续保留。
- Windows 系统属性及标准 BLE 服务按能力适配，不声明覆盖所有品牌或型号。
- 不修改设备设置、音效、固件或系统驱动。不联网、不写电量历史。
- 构建使用 Windows 已有工具；测试、截图和诊断归入 tests/，生产构建输出归入 dist/。
- 发布材料包括兼容范围、许可证、来源说明、贡献指南与 Windows CI；CI 不能代替硬件验收。

## 不包含

主窗口、历史曲线、低电量通知、剩余时间预测、定时查询、未知私有协议自动探测、多电池拆分显示。
